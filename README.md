# AI-PromptCraft – LLM Workflow & Prompt Management App

A Next.js 14 web app for creating, testing, and versioning multi-step LLM prompt chains.

Built and maintained by **Kaushal Raithatha**.

## Features
- Build multi-step prompt templates with variable interpolation
- Real-time streaming via Server-Sent Events (SSE)
- Prompt version history and template management
- OpenAI GPT-4o integration

## Tech Stack
Next.js 14 · TypeScript · TailwindCSS · OpenAI API · PostgreSQL

## Quick Start
```bash
git clone https://github.com/Kausha07/kaushal-dify-ai.git
cd kaushal-dify-ai
npm install
cp .env.example .env.local
npm run dev
```
